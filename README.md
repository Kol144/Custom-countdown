# Cuenta regresiva

Página web sencilla para configurar y grabar una cuenta regresiva.

## Uso

1. Abre `index.html` en Chrome o Edge.
2. Configura horas, minutos y segundos.
3. Opcionalmente, carga una fuente local TTF, OTF o WOFF.
4. Elige 480p, 720p, 1080p o 4K y pulsa **Exportar video**.
5. Mantén la pestaña abierta; al terminar se descarga un archivo WebM.

La grabación se genera en tiempo real con la API de grabación del navegador. No necesita instalación ni dependencias.

## Texturas

Los mapas de plata, metal, cobre, carbono, hielo, mármol y óxido se descargaron de ambientCG bajo CC0 1.0:

- Chrome: [Metal 049 A](https://ambientcg.com/view?id=Metal049A)
- Metal: [Metal 050 A](https://ambientcg.com/view?id=Metal050A)
- Cobre: [Metal 057 A](https://ambientcg.com/view?id=Metal057A)
- Carbono: [Fabric 004](https://ambientcg.com/view?id=Fabric004)
- Hielo: [Ice 003](https://ambientcg.com/view?id=Ice003)
- Mármol: [Marble 012](https://ambientcg.com/view?id=Marble012)
- Óxido: [Rust 009](https://ambientcg.com/view?id=Rust009)

Las texturas de oro, madera, piedra, neón y lava fueron aportadas como referencias por el usuario. El efecto de lava usa específicamente su imagen `lava texture.jpg`.
